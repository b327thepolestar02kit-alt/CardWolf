Yu-Gi-Oh Card Wolf v18

v18 changes:
- Setup screen catch copy changed to 「信用できるのは、自分だけ。」
- Supplied wolf illustration is used as a dark, wolf-themed setup background.
- Player name input added; blank input gets a random Japanese name.
- Non-player-count settings moved into a separate Advanced Settings dialog.
- Win/loss record is shown on the setup screen and resets when the page/browser session starts.
- Added a reset button for the record.
- CPU citizens now strictly prefer truthful clues and will reuse a truthful clue rather than lie when necessary.
- Wolf CPU prefers clues shared by the citizen/wolf cards, then truthful own-card clues, and lies only as a last resort.
- CPU does not use vague expressions.
